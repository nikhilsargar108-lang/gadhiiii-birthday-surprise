GADHIIIIIIIIIIIII BIRTHDAY WEBSITE
===================================

Open index.html in a browser to preview the surprise.

The website is designed as a single shareable page and uses the photos in the assets folder.

To share it as a link:
1. Upload the whole folder to any static website host (for example GitHub Pages or Netlify).
2. Make sure index.html stays at the top level.
3. Send her the resulting public link.

The "Play the song" button opens a YouTube search for "Ye Fitoor Mera"; the song itself is not bundled into the site.

Created for 16 October 2026.
